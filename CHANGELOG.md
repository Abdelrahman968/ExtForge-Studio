# CHANGELOG

All notable changes to **ExtForge Studio** are documented here.

---

## [2.0.0] - 2025-01-01

### New Features

- Complete rewrite as ExtForge Studio v2
- Added Theme Creator with 6 presets, live VS Code mock preview, import/export
- Added Icon Pack Editor with pixel-art canvas, 8 tools, undo/redo, shapes palette
- Added VS Code Settings visual editor with 5 categories and 35+ settings
- Added Snippet Studio with tab-stop syntax and .code-snippets export
- Added Keybindings Editor with search, inline editing, and JSON export
- Added Changelog Builder with version cards and live Markdown preview
- Added Publish Wizard (7-step guided checklist for Marketplace publishing)
- Added 12 ready-to-use Templates
- Added responsive mobile layout with slide-in sidebar
- Added VS Code-style status bar
- Added toast notification system

### Improvements

- Extension Builder now generates 8 output files (up from 3 in v1)
- Added 18 feature modules (up from 6 in v1)
- Added TypeScript / JavaScript language toggle
- Improved code highlighting with semantic token colors
- Added file tab bar for navigating generated files

### Bug Fixes

- Fixed ZIP download falling back to individual file downloads correctly
- Fixed mobile nav not syncing active state with desktop nav
- Fixed canvas not re-initializing on repeated page switches

---

## [1.0.0] - 2024-06-01

### Added

- Initial release of ExtForge Studio
- Extension Builder with package.json, extension.ts, and README.md generation
- TypeScript and JavaScript output support
- 6 feature toggles: Status Bar, WebView, Tree View, Completions, Hover, Diagnostics
- Command and keybinding configuration
- Download all generated files individually
- Basic install guide
